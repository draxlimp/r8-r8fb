## Overview

Minimalist Discord bot source focused on **community**, **moderation**, **information**, **utilities** and **protection**.

- Source only
- No token included
- No fixed private setup
- `start.bat` included for easy startup
- Ready to publish on GitHub

---

## Quick Start

```bash
start.bat
```

The `start.bat` file:
- installs dependencies
- compiles the project
- starts the bot
- creates `config.json` from `config.example.json` on first run

Manual mode:

```bash
npm install
npm run build
npm start
```

## Notes

- This repository is prepared as a **source bot**.
- Keep your token only in `config.json` after local setup.
- `config.json` is ignored by Git.
- `node_modules` is not included.
- The bot can be customized for different communities.
